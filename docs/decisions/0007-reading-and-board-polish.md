# ADR 0007：阅读节奏与黑板呈现

- 日期：2026-11-05
- 状态：已采用

## 背景

M4 验收暴露出一组影响阅读的问题：对白一页太长；行间公式与长段文字挤在一起；
黑板上的公式互相贴住、旧的式子一直留着；图被裁掉；多行公式被截断；课与课之间
没有过渡；自动推断出来的表情与剧情不符。

## 决定

1. **对白分页更短。** 对白单页上限 58 个字符（公式按 2 字计），旁白 90。
   遇到块级 `eq`/`fig` 时，当前页立即结束，公式挂在该页上；其后的文字另起一页。
   （`src/core/pagination.ts`，含单元测试。）
2. **黑板分区。** 公式与图分栏：有图时左栏放图、右栏放公式；只有图时整块板都给图。
   `fig` 只保留最新一张；公式最多保留 2 条。只有在新公式/新图确实需要空间时才丢弃
   最旧的块。进入新小节不擦黑板；跨课（幕间）或离开教室等场景切换才清空，
   后者也可由演出层显式 `board: clear`。
   块之间保留 18 px 间距（`src/core/state.ts`、`src/main.tsx`、`src/style.css`）。
3. **公式缩放到槽位，并设字号上限。** 黑板里的公式/图不再沿用 Typst 的 pt 尺寸和
   `overflow: visible`；渲染时按 em 自然尺寸排版，字号上限为
   `clamp(24px, 2.8vw, 46px)`（1920 逻辑宽下 46px），因此 `P(x)=0` 这类短式不会
   被拉到整块黑板。超过槽位的式子用 `max-width/max-height: 100%` 整体缩小，
   槽位用绝对定位取得确定高度；不裁切、不滚动（`TextContent.fitSvg`）。
   板书区坐标来自背景清单 `regions.board`；只有带该字段的背景（黑板特写）才渲染板书，
   教室广角与湖边长廊不显示公式。
4. **课间幕间。** 跨课（`lesson` 变化）时显示全屏「幕间」卡：上一课完、
   下一课标题；点击或任意键关闭，4.2 秒后自动关闭；期间暂停自动/快进
   （`src/main.tsx`、`.intermission`）。
5. **表情由人工编排。** 删除按关键词自动推断表情的做法（会误判「生气/惊讶」）；
   改为 `data/direction/stage1/**/*.yaml` 里的显式 `expr` cue。放课后的表情按
   `book/lecture/有理函数积分/进阶积分技巧-after.typ` 的批注逐句安排。
6. **旁白时全体变暗。** 有说话人时只点亮说话人、压暗其他角色；旁白页没有说话人，
   所有在场角色统一压暗，让注意力回到文字上。角色离场由演出层的 `hide` cue 控制
   （如严佩追出教室后不再出现）。

## 后果

- 演出层 cue 从 126 增至 228，主要集中在放课后的表情与离场。
- 黑板一屏最多 1 张图 + 2 条公式；多行公式会显得小，但完整可读。
- 幕间不改变 IR/存档，只是 UI 层的一次过渡。
- 深层链接支持 `?unit=<单元>&beat=<序号>`（仅开发构建），用于逐段核对演出。
