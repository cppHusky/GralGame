# ADR 0006：演出层接入运行时

- 日期：2026-11-05
- 状态：已采用

## 背景

M4 要求至少绪论课与放课后具备完整演出。此前 `data/direction/` 只有校验工具，
运行时没有任何消费方：背景、站位、表情、黑板动作全部来自临时启发式
（按发言顺序自动排 3 人），无法表达「换到黑板特写」「清空板书」「地点卡」等编排。

## 决定

1. **核心纯函数**：新增 `src/core/direction.ts`。`applyCommands(state, commands)`
   只改 `GameState` 并返回 `Effect[]`，不读时间/DOM/随机数。`show / expr / move /
   hide / board / set` 改状态；`bgm / se / card / fx / wait` 只产出效果。
2. **状态驱动渲染**：`src/main.tsx` 在进入新句时应用该单元的 cue；进入新小节时
   先应用 `defaults`（背景/BGM），并清空上一节的立绘。渲染层（`Stage`、
   `Blackboard`、`audio`）只消费状态与效果。
3. **黑板特写布局**：背景清单里有 `regions.board` 时，`Blackboard` 用该矩形
   （1920×1080 百分比）定位，公式不再落入浮动面板；`Stage` 只保留当前说话人，
   站在板右侧（x=1560、比例 0.52），把板面中部留给公式。没有 `regions.board`
   的背景继续用浮动黑板面板。
4. **深链仅限开发**：`?unit=stage1/l3/after` 在 `import.meta.env.DEV` 下跳到指定
   小节，供 e2e 与目测使用；生产构建会被移除。
5. **锚点冲突**：同一单元内可能有两句的 16 字锚点相同。`check:direction` 仍要求
   ID 存在且锚点与 ID 一致；命中多句时给出警告并以 ID 为准，`direction:rebase`
   时人工确认。

## 后果

- 演出 YAML 覆盖全部 21 个单元（126 个 cue）；绪论课与放课后包含背景切换、
  立绘上下场、表情变化、板书清空与放课后的暗角。
- 生成 cue 的脚本不在仓库里（一次性辅助）；YAML 已入库，后续人工维护。
- 表情只在角色已在本单元登场时切换，避免与自动站位互相争夺状态。
- 真实 BGM/SE 仍未交付，运行时继续用合成占位；`bgm`/`se` 命令已可用，等素材
  入库后只需补清单与 cue。
